## 修复

1. **导光间灯路箭头**
   - `draw_guide_beams` 不再绘制三角箭头；未对准时只保留一条很短的弱方向提示线和灯座光点。
   - 对齐后的灯路光束、灯座朝向名与 `（上/右/下/左）` 文本保留。

2. **近战表现**
   - 颜色由单一金橙改为「青绿外层 + 苍白主弧 + 金色刃口 + 白色细缝」。
   - 增加两道半透明残影弧、挥砍星芒、玩家身边青色冲击弧。
   - 末端 14 枚三色粒子（青绿/薄荷/浅金），粒子尺寸 2～4px，带拖尾；命中火花同步换成薄荷/青绿/浅金。
   - 近战射程 22→26 保持不变。

3. **中文提示**
   - 支线奖励显示改为「澄明镜」「余温符」；内部稳定 ID `clear_mirror` / `ember_talisman` 仍只用于存档。
   - 修复 `ember_talisman` 裸露在完成提示中的问题。

4. **敌人返回不回血**
   - T1 基础返回和特殊敌人返回都只重置位置/警戒，不再 `hp = spec.hp`、不再恢复护壳。
   - A15 回归改为「返回后 hp 保持 36」，不再期待回满。
