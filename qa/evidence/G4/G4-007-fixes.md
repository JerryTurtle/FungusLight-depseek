# G4-007 战斗表现与反馈修复

日期：2026-10-18。依据用户试玩反馈；G4 已通过，本构建为进入 G5 前的表现与可读性修复。

## 1. 初燃（净光）特效

- 充能阶段：灯尖出现短促的强光核心与扩散光晕。
- 释放：宽压力光晕 + 中等光束 + 白热核心 + 白色细缝的四层短促爆发。
- 命中点：扩张冲击环、12 枚火花/碎屑与拖尾；低特效/减少闪烁设置下降级。
- HUD 不遮挡战斗；表现由固定 tick 驱动，回放仍一致。

## 2. 近战特效与判定

- 高速横斩月牙：多层金色弧光，中心宽、两端渐隐；刃口高亮与拖尾。
- 命中/挥击末端增加方向性火花粒子；命中反馈仍由 `combat_feedback` 的火花系统叠加。
- 近战 `range` 从 **22 → 26**，角度 90° 不变；A04 边界测试同步更新。

## 3. 伤员素材

- 营地 `伤员` 改为从已验收 Cleric 精灵派生的 umber/灰绿配色：无灯杖、头部/手臂绷带、红点、木拐杖；与世界原创角色同像素尺度。
- 不再使用会被误认为 NPC 的红蘑菇装饰；水管隔间仅保留绒和正常环境装饰。

## 4. 菌根前厅 Boss

- EL1「守门者」移除半血后恢复两层护壳的 `rearm`：旧逻辑会让玩家读成“杀不死/壳反复回来”。
- 保留初始两层护壳、灯击削壳、护壳减伤等可读机制。
- HUD 在精英/Boss 存活时显示 `目标：守门者 生命/护甲`。
- 新增 `test_g4_boss.gd` 的 EL1 检查：半血不再 rearm、可被击杀；`test_enemies` 同步更新。
