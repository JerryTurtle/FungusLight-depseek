# G6-007 开始界面与像素字体优化

- 构建：G6-007
- 日期：2026-10-19
- 范围：开始界面、设置入口、游戏顶部剧情/底部操作提示字体。
- 结论：发布候选，不是 G6 通过；用户书面验收前保持 `in_progress`。

## 修改

### 1. 开始界面不再使用黑框

- 删除标题页的 740×520 黑色面板、边框和页面说明段落。
- 改为全屏透明菜单：背景图 + 36% 暗色柔光层（不是方框），标题和按钮直接叠在背景上。
- 标题/菜单使用 Fusion Pixel 12px 像素字体，文字加 4px 深色描边；按钮无底板、无边框，悬停暖金色、按下琥珀色。
- 居中标题「菌灯之下」56px，下面「灯与根」18px，再下面为菜单。

### 2. 标题居中，去掉剧情介绍和开场回看

- 标题、副标题和菜单全部水平居中；菜单 VBox 垂直居中。
- 删除标题页的故事介绍段落和版本号展示。
- 删除「重看开场故事」按钮；新游戏仍默认播放五幕开场。
- 标题页只保留：新游戏、继续游戏、读取存档、设置、退出。

### 3. 修复标题页「设置」没有反应

- 根因：`settings_panel` 在节点树中早于 `title_bg`/`overlay` 添加；从标题打开时面板虽然 `show()`，但被标题背景盖住，看起来像点击无反应。
- 修复：`settings_panel.z_index = 100`；标题页打开设置后完整绘制在背景/标题层之上。
- `test_g6_release` 新增 `settings_panel.z_index >= 100` 断言；窗口截图 `G6-007-title-settings.png` 已确认。

### 4. 顶部剧情与底部操作提示使用像素字体

- `campaign.gd` 为顶部目标 `hud` 和底部状态 `status` 显式设置 `Fusion Pixel 12px` 字体，不再依赖主题回退。
- 字号仍为 20px，保留描边、自动换行与行数限制。
- 菜单标题/段落/按钮也统一使用同一像素字体。
