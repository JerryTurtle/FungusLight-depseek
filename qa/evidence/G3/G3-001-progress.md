# G3-001：H2批准与存档基础

日期：2026-10-17。前置：用户明确批准 G2-007 的 H2，原文见 `qa/H2-approval.md`。本次没有改动已审角色、动作、镜头或战斗参数。

## 本轮实现

- `save_store.gd` 提供 manual_1/manual_2/manual_3/auto 四槽，存档目录与设置/审核记录分开。
- 六项安全条件均须明确布尔真：无警戒敌人、无危险物、玩家空闲、无阻断演出、可走落点、无精英/Boss战。缺失条件及路径穿越槽名均拒绝。
- 版本和必需字段校验、有效数值校验、顶层字段白名单；世界进度与奖励/资源在同一快照，不单独保存奖励标记。
- 临时文件写入并回读，保存前一有效主档为备份，再替换主档。主档损坏时保留既有有效备份；读取不自动回退，调用方必须向玩家展示恢复选择。
- 手动槽覆盖必须显式确认；自动槽允许更新。失败返回可展示的中文信息。
- 根目录 AGENTS.md 固化每轮验证、接续记录、Conventional Commits提交及推送要求。

## 真实验证

命令：`python tools/test_save.py`。Godot 4.3 headless 实际读写隔离磁盘目录；65项检查，0失败。证据：`qa/G3-001-save-tests.log`。

覆盖四槽、新实例读取、槽间隔离、覆盖确认、六种安全阻断、缺失字段、非法药剂、版本不兼容、截断JSON、无备份损坏、显式备份恢复、奖励与资源同步回退、坏主档不污染好备份、遗留临时文件、临时写入失败不改变原主档/备份、目录创建失败。

日志中的 `Could not create directory .../blocked/subdir` 是有意以普通文件阻塞目录的错误注入，验证模块返回 io 错误；不是正常保存失败。首次测试目录使用 res://../ 解析失败，已改用规范化绝对路径，最终重跑通过。未声称完成系统断电/跨进程崩溃注入或文件系统事务级保证。
