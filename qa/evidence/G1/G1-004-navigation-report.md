# G1-004 绕障与动态门

2026-10-16。G1仍为in_progress；G2/H2未开始。

## 实现与修复
- 有界80×45格、4像素格距、四邻接BFS。边连接使用同一实体半径5的墙/门扫掠查询；避免对角切墙。
- 初版8像素格在16像素窄口漏采可通行点，回归失败。改为4像素格后该场景到达目标且全程不穿墙。
- 无障碍直线优先；绕障每15物理步重算；动态门变更即清缓存。局部阻挡采用固定顺序侧移，仍受实体碰撞限制。
- 门只有一个矩形定义，同时供渲染、移动、射线与寻路使用；角色占据门范围时拒绝关闭。G键为灰盒测试控制。
- 初始警戒需要112像素内且有视线；已警戒可绕障追击。失去视线且超过144像素持续120步后回位，回位不攻击，抵达出生点后一次性恢复生命。
- 无路持续180步后仅在出生点未被墙或存活实体占用时恢复，不产生死亡/奖励事件。
- T1按方案短前扑，在有效段第一步前进3像素（受实体/墙阻挡），衔接20像素起手距离与18像素判定。参数及寻路间隔等集中在actions.json。
