#### G3存档接入契约

`save_slot(slot, snapshot, safety, overwrite_confirmed=false)`和`load_slot(slot, use_backup=false)`返回带ok及message/错误code的Dictionary；读取失败可提供backup_available，UI需让玩家明确选择恢复。槽名仅manual_1/manual_2/manual_3/auto。覆盖确认布尔值只能来自实际确认操作。

快照必须包含schema_version=1、build_id、chapter_id、node_id、safe_position=[x,y]、health/focus/potions/effective_seconds，以及quests/story/puzzles/encounters/rewards/skills/upgrades/equipment字典。存档模块仅检查这些字典类型，具体稳定ID、合法状态、属性上限与地图落点由待开发的世界适配层校验，不能把外层校验当作完整校验。

安全字典六项均须实际布尔true：no_alert_enemies、no_hazards、player_idle、no_blocking_event、walkable_position、no_elite_battle。测试传值仅用于单测，正式调用必须从世界计算；战斗/阻断演出期间不能保存半完成事件。主线存档位于user_storage目录下saves，设置和审核记录另存。玩家死亡、任务/奖励恢复及最近存档选择仍由接入层实现。
