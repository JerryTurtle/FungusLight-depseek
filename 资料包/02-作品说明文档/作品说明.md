## 1. 作品概览

**类型：** 单机、俯视角、像素风动作 RPG（近战 + 法术 + 闪避）。

**一句话：** 守灯人岚提着灯杖深入地下避难所与废弃水道，查明菌灯失控、菌根断水与共生核心异变的真相，并在终章做出"恢复共生"或"封存撤离"的选择。

**内容规模（G6-012 实现）：**

| 维度 | 规模 |
| --- | --- |
| 章节 | 5 章：序章、第一章、第二章、第三章、终章 |
| 主线节点 / 房间 | 37 个 |
| 主线遭遇 | 37 组（教学 1 组 + E01～E36） |
| 敌人模板 | T1 追击者、T2 投孢者、T3 冲锋者、T4 护冠守卫、T5 静止孢囊、T6 强化投孢者、EL1 孢冠精英、EL2 巡渠精英、Boss 母体 |
| 主线机关 / 调查 | 9 个（P01～P09） |
| 成长里程碑 | 4 个（M1～M4，每个二选一强化） |
| 装备 | 6 件（灯镜 3 + 护符 3） |
| 剧情事件 / 场景文本 | S01～S10 主线剧情事件、L01～L20 场景记录 |

| 目标时长 | 用户已确认 **20 分钟**目标（原 1 小时目标已由用户调整） |

**时长口径说明：** 自动路线（引擎输入回放）默认路线 **707.7 秒 / 0 死亡**，整段跳过 **607.4 秒 / 0 死亡**。它是机器人最短合法路线，不等于真人阅读、探索、战斗时的实际时长，也不能当作 20 分钟真人时长的证明。

## 2. 故事与世界观

- **世界：** 地下避难所依靠"菌灯"照明与净水生活。灯网与菌根共享同一水脉，人与菌群曾立下旧约——"灯与根，同饮一脉水；人取水须留灯，根供水须留路；违约者，以渴偿还"。
- **起因：** 避难所缺水，前代守灯人/技师禾抬高泵压并签下砍根令；菌根断水枯裂，菌群从"守水"转为"反击"，菌灯随之失控。
- **主线：** 岚从营地最后一盏灯出发，沿旧矿道、菌洞、泵站、王庭一路取得三件证据——**断根切口、抽水记录、旧约拓文**——最终在核心室面对母体并做出选择。
- **人物：** 绒（营地证人）、禾（以残页与记录出现）、砾（第二章支路获救，留条不跟随）、菌王（旧王留声，非最终敌人）、母体（根心在缺水中长成的新意志）。
- **叙事方式：** 短对白 + 场景记录 + 机关/证据推进，不依赖长篇 CG、配音或运镜。

## 3. 玩法介绍

### 3.1 核心循环

```
探索房间 → 观察/交互（E、Q）→ 机关或战斗 → 取得证据/资源/成长 → 通过石拱传送门进入下一房间
```

- **探索：** 37 个手工配置的房间，含墙、门、传送门、箱子、阀门、刻字、灯座等交互物；小地图显示当前位置。
- **战斗：** 即时动作战斗，60Hz 固定物理步；近战、三种法术、闪避与药剂构成完整资源循环。
- **机关：** 9 个主线机关/调查均为"观察 + 操作 + 反馈"的短解谜，可重试，不会把玩家卡死。
- **成长：** 4 次灯芯里程碑（固定提升 + 二选一强化），在安全休息点免费重选。
- **存读档：** 自动存档 + 3 个手动槽，坏档可用备份恢复；死亡回到最近安全检查点。

### 3.2 战斗系统与动作参数

战斗使用**单角色、四向朝向、鼠标瞄准**的俯视角动作规则；所有动作参数与代码共用 `game/data/actions.json` 一份数据，不在 UI 里另写一套数值。

| 动作 | 按键 | 前摇/有效/后摇（物理步，60Hz） | 消耗 / 冷却（步） | 主要效果 |
| --- | --- | --- | --- | --- |
| 灯击（近战） | 鼠标左键（可长按连击） | 6 / 5 / 11 | 0 / 0 | 18 伤害，半径 26，扇形 130°；面向上/下时有内侧贴身判定 |
| 净光（直线） | 鼠标右键 | 12 / 6 / 9 | 20 专注 / 72 | 24 伤害，长 96、宽 6；穿透光路上的所有敌人，遇墙截断；先削 1 层护壳 |
| 护灯（护盾） | 1 | 9 / 0 / 9 | 25 专注 / 480 | 护盾容量 25，持续 120 步；吸收伤害但不免打断 |
| 灯雨（范围） | 2 | 21 / 0 / 9 | 35 专注 / 360 | 选点 112、半径 28，释放后 30 步落光，45 伤害；非法落点不扣费 |
| 闪避 | 空格 | 0 / 11 / 0 | 0 / 60 | 位移 32 像素，前 6 步无敌；撞墙/实体则停止，不穿墙 |
| 饮用药剂 | R | 36 步使用 | 消耗 1 瓶 | 恢复 35 生命；移动、闪避或受击会取消且不扣药 |

**基础属性：** 生命 100 / 专注 100，移动 80 像素/秒，专注恢复 3/秒；有效灯击每动作回能 4。

**战斗规则要点：**

- 攻击有前摇、有效、后摇三段；前摇多数可被闪避取消，有效段不可取消，后摇末段可取消。
- 同一攻击对同一目标只结算一次；同帧互击按稳定顺序结算；死亡在整批结算后处理。
- 敌人有 0～2 层护壳，每层减少 25% 直接伤害；净光可削壳，破壳有独立表现与音效。
- 玩家受击后有 30 步伤害保护；毒区、孢毒有独立 tick 上限，不无限叠加。
- 敌人脱战回位时不回血、不重复发奖；普通攻击不会无限压制精英。

### 3.3 敌人与 Boss

| ID | 敌人 | 生命 / 速度 | 行为与克制 |
| --- | --- | --- | --- |
| T1 | 菌壳追击者 | 72 / 46 | 接近后短前摇近击；诱招后反击，可被打断 |
| T2 | 投孢者 | 60 / 34 | 保持距离投孢，弹体附孢毒；视线被挡会换位 |
| T3 | 巡渠冲锋者 | 110 / 40（冲锋 160） | 方向线预警后锁定冲锋；撞墙结束，不追踪 |
| T4 | 孢冠守卫 | 130 / 28 | 初始 2 层护壳 + 慢扇形扫击；需先用净光削壳 |
| T5 | 静止孢囊 | 30 / 0 | 玩家靠近触发爆裂并留下毒区；提前击毁可避免 |
| T6 | 强化投孢者 | 90 / 34 | 双弹投孢，发射点可见；受 20 弹体上限约束 |
| EL1 | 孢冠精英 | 450 / 28 | 半血时仅补一次 2 层壳，有 0.8 秒预告 |
| EL2 | 巡渠精英 | 520 / 38 | 冲锋与固定水道预警交替，不会同时封死所有路 |
| BOSS | 母体 | 2200 / 20 | 三阶段：100%～70% 扇扫+护壳；70%～35% 水道反流与交替安全区；35% 以下孢囊威胁与核心暴露 |

Boss 阶段跨阈值时生命会被夹到 70%/35%，不会一次跨阶段；转阶段清理旧危险区并给安全窗口；核心暴露窗口可被近战/法术命中。Boss BGM 进入核心室播放，离开或回标题停止，音量跟随设置。

### 3.4 关卡、机关与探索

- **37 个房间**覆盖营地、矿道、菌洞、泵站、王庭、核心室与尾声；房间出口统一为**石拱传送门**（封印/开启两态），门牌写明"通往/返回 目的地"。
- **9 个主线机关/调查：**

| ID | 内容 | 操作要点 |
| --- | --- | --- |
| P01 | 取备用灯芯并复亮出口灯座 | 跟随灯线、调查箱子、把灯芯装入灯座 |
| P02 | 对齐三座导光装置 | 观察刻痕，切换方向，让光路连通 |
| P03 | 比对断根与旧矿记录 | 扫描切口、查看记录，在两种解释中选与证据匹配的一项 |
| P04 | 重接分流通道 | 按流向图操作阀门，分段改变水位，可复位 |
| P05 | 打开被困者出口 | 从安全侧切断污染根，再打开手动门闩 |
| P06 | 校验残液与抽水记录 | 对照两个测量点，启动备用储水 |
| P07 | 显露共同供给网络 | 沿三段管线扫描节点，连接人类水管与菌根 |
| P08 | 解读旧约并打开撤离路 | 把三证据放入对应刻槽，开启门体与捷径 |
| P09 | 校准最终泵站 | 按流向规则分三步稳定压力 |

- **交互优先级：** 出口、宝箱、阀门、剧情物优先于休息灯座；站在灯座旁按 E 休息补满药剂与生命，不会抢走出口交互。
- **小地图：** 显示当前房间、已探索区域与玩家位置，便于在 37 个房间中定位。
- **回声扫描（Q）：** 切换环境显示，高亮可交互物与证据物，不消耗资源、不改变伤害。

### 3.5 成长、装备与补给

**四个里程碑（M1～M4）** 各给固定提升 + 一个二选一强化：

| 里程碑 | 时机 | 二选一 |
| --- | --- | --- |
| M1 初燃 | 序章 P01 复亮、教学/E01 完成后 | 灯击伤害 +15% 或 净光伤害 +15% |
| M2 稳焰 | 第一章精英后 | 有效灯击回能 4→6 或 护灯容量 +10 |
| M3 导流 | 第二章支路、巡渠精英与记录完成后 | 净光消耗 −5 或 灯雨伤害 +25% |
| M4 明辨 | 第三章旧约与撤离通路完成后 | 生命上限额外 +20 或 专注上限额外 +20 |

- 生命曲线 100 → 110 → 120 → 130 → 140（M4 可选 +20）；专注上限 100 → 100 → 110 → 110 → 120（M4 可选 +20）；选择强化不回满血。
- **6 件装备：** 聚束镜、节流镜、澄明镜、守灯结、工匠扣、余温符；灯镜与护符各装备一件，效果为真实数值/机制修正（非占位）。
- **补给：** 药剂上限 3 瓶，休息灯座补满；药剂使用会被移动/闪避/受击打断，完成时才消耗。
- **休息点：** 补满生命/药剂、调整强化与装备、触发自动存档；战斗中与 Boss 战中不可保存。

### 3.6 剧情与结局

- **三证据：** `root_cut`（S04 断根切口）、`pump_record`（S07 抽水记录/禾残页）、`covenant`（S08 旧约拓文）。
- **恢复共生循环：** 需要三证据齐备并完成 P09 泵站校准；结局说明"限流共生，需要共同维护"。
- **封存并撤离：** 需要 P06 备用储水启用并完成 P08 撤离通路；结局说明"带储水撤离，放弃地下旧居"。
- 结局在核心室显式确认，确认前可返回查看证据、保存；选择后写入独立结局备份，尾声显示结局、有效时长与章节记录，可返回标题或读取结局前的独立备份。

### 3.7 表现与音画

- **12 类特效**覆盖孢子/尘埃、菌灯呼吸、水流、回声扫描、灯杖挥击、命中/受击、净光、破壳、护灯、灯雨、敌方预警/孢毒、Boss 阶段/死亡。
- **技能特效：** 灯击有弧光、内圈符文、残影与青绿/金色粒子；净光有三股光丝、灯口符文、端部光晕；灯雨有法阵、落线、光柱、三重冲击环与像素水花；传送门为暖色椭圆内部微光与悬浮，不带外侧粒子碰撞。
- **音效：** 7 个程序合成音效（挥击/命中/施法/受击/破壳/护盾受击/灯雨落地）+ 1 首原创循环 Boss BGM；无第三方采样。
- **可访问性设置：** 全屏、低特效、减少动态、降低闪光、屏幕震动、音效/音乐音量；低特效档仍保留危险轮廓与预警。

## 4. 运行环境

> 以下为**验证/建议环境**，不是官方最低配置；G6-013 同时提供 32 位与 64 位 Windows 构建。

| 项目 | 要求 / 建议 |
| --- | --- |
| 操作系统 | Windows 7 SP1 / 8 / 8.1（Godot 官方 best-effort）、Windows 10 / 11；32 位与 64 位均可 |
| CPU | 支持 SSE2 的 x86 处理器（32 位构建可在老双核上运行；建议双核 2.0 GHz 及以上） |

| 显示 | 默认 1280×720 视口，窗口会按屏幕可用区等比缩放并居中；可全屏；保持 16:9 比例，非 16:9 时留边 |
| 存储 | 解压后约 210 MiB（32 位 exe 87.5 MiB + 64 位 exe 80.3 MiB + 两份 pck），另加存档/设置/日志少量空间 |

| 音频 | 可选；无音频设备时可静音运行 |

**首次运行：** 解压后优先双击 `Game/开始游戏.cmd`：64 位系统自动选 64 位构建，32 位系统自动选 32 位构建；启动失败时它会自动再尝试 ANGLE/D3D11 兼容模式。也可以直接双击 `Game/FungusLight.exe`（默认 32 位构建，32/64 位 Windows 都可运行）。exe 与 pck 必须保持同目录。第一次运行会在用户目录创建 `FungusLight` 配置、存档目录和 `startup-info.txt`。

**存档位置：** `%APPDATA%\FungusLight\saves\`；若不可写，会依次尝试 `LOCALAPPDATA`、文档目录或 exe 旁 `用户数据/`。游戏目录内不写入个人存档。

## 5. 依赖说明

### 5.1 运行游戏：零外部依赖

- Godot 引擎已打包进 `FungusLight.exe`，无需安装 Godot 编辑器、Python、.NET、Node 或任何 SDK。
- 字体、音频、图块、脚本资源全部在 `FungusLight.pck` 内，不依赖开发机路径。
- 不联网、不读取注册表、不需要管理员权限。
- **故障排查：** 若极少数精简系统提示缺少系统运行库，可安装 Microsoft Visual C++ 2015–2022 运行库（Windows 10/11 通常已自带）；SmartScreen 可能提示未知发布者，可选择"更多信息 → 仍要运行"。

### 6.2 界面与流程

1. **标题界面：** 新游戏 / 继续 / 读取 / 设置 / 退出；像素字体、居中菜单、菌洞与守灯人背景图。
2. **开场：** 新游戏播放五幕像素插画（菌洞村落、泵站、断水、岚与最后灯、灯根核心），回车/空格/左键推进，Esc 跳过。
3. **HUD：** 左上透明信息层（小头像、生命、精力、护灯当前/上限、三瓶药剂、用时）；右下五个技能图标（冷却遮罩/秒数、锁标、"耗 N"）；顶部"章节 . 房间"。
4. **对话：** 底部 RPG 对话框，名字牌 + 打字机效果 + ▼ 提示；Tab 跳过本段，选项页不能跳过代选。
5. **暂停：** 继续、保存、读取、装备配置、设置、返回标题；打开时冻结敌人、技能与危险区。
6. **死亡：** 重试最近检查点 / 读取存档 / 返回标题。
7. **结局：** 显示结局、本次用时、章节记录；可返回标题或读取结局前独立备份。

### 6.3 存档与设置

- **自动存档：** 新游戏、安全检查点、休息、成长选择、章节推进、清场后与结局选择时写入。
- **手动存档：** 暂停菜单可保存到 3 个手动槽；覆盖已有槽需确认，提示会写明槽位名称。
- **读取：** 标题或暂停菜单的"读取存档"，显示槽位、区域与有效时长；空槽、损坏槽、仅备份可恢复分别标注。
- **坏档恢复：** 损坏主档会保留有效 `.bak`；读取失败时可选择恢复上一次备份。
- **安全条件：** 无警戒敌人、无在途危险物、主角未处于动作/受击、未播放阻断演出、站在可通行地面；精英/Boss 战中不可保存。
- **设置项：** 全屏、低特效、减少动态、降低闪光、屏幕震动、音效音量、音乐音量；写入用户目录 `presentation.cfg`。本版本不提供按键重设。

## 7. 已知问题与边界

- **无安装器 / 无代码签名：** 发布形态为便携 exe + pck，SmartScreen 可能拦截；需保持两文件同目录。
- **G5 单独阶段被跳过：** 按用户指示在 G4-009 后直接进入 G6；地区音乐、完整按键重设与长时负载复测未作为本次发布阻断项。本包只有 7 个程序音效 + 1 首 Boss BGM，没有地区循环音乐。
- **不支持按键重设 / 手柄：** WASD、鼠标左右键、1/2、空格、E/Q/R、Esc/F1 为固定键位；不响应方向键移动。
- **20 分钟目标，不是 60 分钟：** 用户已将目标从 1 小时调整为 20 分钟；自动路线 707.7 秒不是真人时长。
- **传送门与技能特效的观感仍需实机确认：** 自动检查覆盖路线、对象与碰撞，但观感、手感、音量属于人耳/人眼验收范围。
- **剧情文本仍需人工通读：** S01～S10、L01～L20 已统一时间线，仍建议按 37 节点实际阅读。
- **路线矩阵为历史基线：** G6-012 只重跑默认路线与整段跳过路线；8/8 矩阵（612.3～728.3 秒）为 G6-003 历史基线，不代表 G6-012 重跑结果。
- **原始素材 / 生成图 / BGM 许可未确认：** 见 §5.3；在确认前仅用于本项目验收，不公开商业分发。
- **无云存档 / 无多语言 / 无成就：** 存档为本机文件，仅简体中文。
- **自动化 ≠ 真人验收：** 自动化使用 Godot headless/导出二进制与引擎输入注入，不替代真实键鼠、显示器刷新率、音频设备、Alt+Tab 焦点体验。
