# 《菌灯之下》安装与运行说明

## 1. 包内是什么

`FungusLight-G6-012-Release.zip` 是 **v1.0.0 / G6-012** 的正式 Windows 发布包（免安装便携版），解压后为五个目录：

| 目录 | 内容 |
| --- | --- |
| `Game/` | 可直接运行的游戏：`FungusLight.exe`、`FungusLight.pck`、`开始游戏.cmd`、`README.txt` |
| `Source/` | 当前 Godot 4.3 工程源码与生成脚本 |
| `Docs/` | 操作说明、验收说明、已知问题、素材边界 |
| `QA/` | 验收记录、截图、测试证据与哈希 |
| `Licenses/` | 项目、引擎、字体、素材来源与许可 |

> 本作品**没有 setup.exe 安装器**，也没有代码签名；发布形态就是便携目录 + zip。这与项目已知边界一致：Windows SmartScreen 可能提示"未知发布者"。

## 2. 安装（解压）步骤

1. 把 `FungusLight-G6-012-Release.zip` 解压到任意**可写目录**（例如 `D:\Games\FungusLight`）。
   - 不要让 `FungusLight.exe` 与 `FungusLight.pck` 分开；两者必须保持同目录。
2. 建议保留完整五目录结构；只运行游戏时，`Game/` 内的 exe + pck 即可。
3. 首次运行会在用户目录创建 `FungusLight` 配置与存档目录，不需要管理员权限。
4. 如果解压到受保护目录（如 `C:\Program Files`）导致无法写存档，游戏会自动尝试 `LOCALAPPDATA`、文档目录或 exe 旁 `用户数据/`。

## 3. 启动游戏

- 双击 `Game/开始游戏.cmd`，或直接双击 `Game/FungusLight.exe`。
- 发布构建默认进入**标题画面**（新游戏 / 继续 / 读取 / 设置 / 退出），不会进入开发审核台。
- 新游戏会播放五幕开场；回车 / 空格 / 鼠标左键推进，`Esc` 跳过。
- 不需要安装 Godot 编辑器、Python 或任何开发环境。

## 4. 运行环境

| 项目 | 建议 |
| --- | --- |
| 系统 | Windows 10 / 11 64 位 |
| 内存 | 4 GB 以上 |
| 显卡 | 支持 OpenGL 3.3（集成显卡通常即可） |
| 分辨率 | 1280×720 窗口，可全屏 |
| 输入 | 键盘 + 鼠标 |
| 网络 | 不需要 |
| 空间 | 解压后约 102.5 MiB（十进制约 107.5 MB），另加存档少量空间 |

完整的运行环境、依赖与许可说明见 [作品说明.md](../02-作品说明文档/作品说明.md)。

## 6. 存档与设置位置

- 存档：`%APPDATA%\FungusLight\saves\`（或程序选择的后备用户目录）。
- 设置：用户目录 `presentation.cfg`。
- 运行报告：用户目录 `run_report.json`。
- 发布包与游戏目录**不包含**个人存档或日志。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| SmartScreen 拦截 | 点击"更多信息 → 仍要运行"；本项目无代码签名 |
| 窗口打不开 / 报 pck 缺失 | 确认 exe 与 pck 同目录，且未被杀毒软件隔离 |
| 没有声音 | 检查设置中的音效/音乐音量；本版本只有程序音效与 Boss BGM，没有地区音乐 |
| 存档不可写 | 把游戏放到用户可写目录，或查看标题/暂停菜单的存档提示 |
| 字体显示异常 | 使用发布包内完整 pck，不要只复制 exe |
| 提示缺少运行库 | 安装 Microsoft Visual C++ 2015–2022 运行库（Windows 10/11 通常已带） |
| 按键不响应 | 确认使用 WASD（本版本不支持方向键），且窗口处于焦点 |
