# 《菌灯之下》安装与运行说明

## 1. 包内是什么

`FungusLight-G6-013-Release.zip` 是 **v1.0.1 / G6-013** 的正式 Windows 发布包（免安装便携版），解压后为五个目录：

| 目录 | 内容 |
| --- | --- |
| `Game/` | 可直接运行的游戏：`FungusLight.exe`（32 位，32/64 位 Windows 均可运行）、`FungusLight.pck`、`64/FungusLight.exe`（64 位）、`64/FungusLight.pck`、`开始游戏.cmd`、`兼容模式启动.cmd`、`系统检查.cmd`、`README.txt` |
| `Source/` | 当前 Godot 4.3 工程源码与生成脚本 |
| `Docs/` | 操作说明、验收说明、已知问题、兼容性说明、素材边界 |
| `QA/` | 验收记录、截图、测试证据与哈希 |
| `Licenses/` | 项目、引擎、字体、素材来源与许可 |

> 本作品**没有 setup.exe 安装器**，也没有代码签名；发布形态就是便携目录 + zip。这与项目已知边界一致：Windows SmartScreen 可能提示"未知发布者"。

## 2. 安装（解压）步骤

1. 把 `FungusLight-G6-013-Release.zip` 解压到任意**可写目录**（例如 `D:\Games\FungusLight`）。
   - 不要让 `FungusLight.exe` 与 `FungusLight.pck` 分开；两者必须保持同目录。`64/` 目录内的 exe 与 pck 也必须保持同目录。
2. 建议保留完整五目录结构；只运行游戏时，`Game/` 内的文件即可。
3. 首次运行会在用户目录创建 `FungusLight` 配置、存档目录和 `startup-info.txt`，不需要管理员权限。
4. 如果解压到受保护目录（如 `C:\Program Files`）导致无法写存档，游戏会自动尝试 `LOCALAPPDATA`、文档目录或 exe 旁 `用户数据/`。

## 3. 启动游戏

- 推荐双击 `Game/开始游戏.cmd`：64 位 Windows 自动选择 64 位构建，32 位 Windows 自动选择 32 位构建；启动失败时会自动再尝试一次 ANGLE/D3D11 兼容模式。
- 也可以直接双击 `Game/FungusLight.exe`：它是 32 位构建，32 位和 64 位 Windows 都能直接运行。64 位 Windows 想用 64 位构建，双击 `Game/64/FungusLight.exe`（或直接用启动器）。
- **老显卡/黑屏/闪退**：双击 `Game/兼容模式启动.cmd`，强制使用 ANGLE/D3D11 渲染。
- 仍然无法启动：双击 `Game/系统检查.cmd` 生成 `diagnostic.txt`，并把 `startup-log.txt`、用户目录的 `startup-info.txt` 一起反馈。
- 发布构建默认进入**标题画面**（新游戏 / 继续 / 读取 / 设置 / 退出），不会进入开发审核台。
- 新游戏会播放五幕开场；回车 / 空格 / 鼠标左键推进，`Esc` 跳过。
- 不需要安装 Godot 编辑器、Python 或任何开发环境。

## 4. 运行环境

| 项目 | 建议 |
| --- | --- |
| 系统 | Windows 7 SP1 / 8 / 8.1（best effort）或 Windows 10 / 11；32 位与 64 位均可 |
| 内存 | 2 GB 以上（32 位进程上限 2 GB）；建议 4 GB |
| 显卡 | 支持 OpenGL 3.3 的显卡；原生 OpenGL 不可用时可尝试 ANGLE/D3D11 兼容模式 |
| 分辨率 | 默认 1280×720 视口，窗口按屏幕可用区缩放并居中，可全屏 |
| 输入 | 键盘 + 鼠标 |
| 网络 | 不需要 |
| 空间 | 解压后约 210 MiB（含 32/64 位两个构建），另加存档少量空间 |

完整的运行环境、依赖与许可说明见 [作品说明.md](../02-作品说明文档/作品说明.md)。

## 6. 存档与设置位置

- 存档：`%APPDATA%\FungusLight\saves\`（或程序选择的后备用户目录）。
- 设置：用户目录 `presentation.cfg`。
- 运行报告：用户目录 `run_report.json`。
- 启动信息：用户目录 `startup-info.txt` 与 `compat_report.json`（记录系统、显卡、渲染驱动、窗口和存档目录）。
- 启动日志：启动器写入 `%LOCALAPPDATA%\FungusLight\startup-log.txt`；兼容模式写入 `compat-log.txt`。
- 发布包与游戏目录**不包含**个人存档或日志。

## 7. 校验

```powershell
Get-FileHash .\FungusLight-G6-013-Release.zip -Algorithm SHA256
Get-FileHash .\Game\FungusLight.exe, .\Game\FungusLight.pck, .\Game\64\FungusLight.exe, .\Game\64\FungusLight.pck -Algorithm SHA256
```

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| SmartScreen 拦截 | 点击"更多信息 → 仍要运行"；本项目无代码签名 |
| 32 位 Windows 直接报"不是有效的 Win32 应用程序" | 请使用 G6-013：`FungusLight.exe` 默认已是 32 位构建，或双击 `开始游戏.cmd` / `64\` 之外的启动器 |
| 黑屏 / 闪退 / 提示显卡驱动不支持 | 双击 `兼容模式启动.cmd` 强制 ANGLE/D3D11；仍失败请更新显卡驱动 |
| 窗口打不开 / 报 pck 缺失 | 确认 exe 与 pck 同目录，且未被杀毒软件隔离；`64/` 目录同理 |
| 启动后什么都没发生 | 双击 `系统检查.cmd`，把 `diagnostic.txt`、`startup-log.txt`、`startup-info.txt` 一起反馈 |
| 没有声音 | 检查设置中的音效/音乐音量；本版本只有程序音效与 Boss BGM，没有地区音乐 |
| 存档不可写 | 把游戏放到用户可写目录，或查看标题/暂停菜单的存档提示 |
| 字体显示异常 | 使用发布包内完整 pck，不要只复制 exe |
| 提示缺少 d3d11.dll / 运行库 | 32/64 位官方模板自带运行库；若系统缺少 d3d11.dll，请安装 Windows 7 Platform Update 或升级系统 |
| 按键不响应 | 确认使用 WASD（本版本不支持方向键），且窗口处于焦点 |
