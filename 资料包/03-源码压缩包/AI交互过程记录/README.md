## 记录口径

- 来源：DSH 会话日志与项目内整理文档；用户内容保留主要措辞和完整要求，AI 回复尽量简写。
- 省略工具调用、工作进度播报与环境元数据；纯"继续/确认"类消息并入相邻轮次。
- 早期提案与中间版本只用于回顾交流过程，**不代表最终规格**；最终规格以 `策划输出/菌灯之下_游戏开发策划方案.md` 与发布包为准。
- 记录中的路径可能是历史路径；目录迁移表见 `qa/maintenance/path-migration.json`。
- 原始记录（`与AI交互内容-*.md`）中的相对链接按其在原仓库 `docs/` 下的位置书写，复制到本目录后部分链接不能直接跳转；**原文内容未改动**，需要时请到源码包 `docs/` 或 Git 仓库查看对应文件。
