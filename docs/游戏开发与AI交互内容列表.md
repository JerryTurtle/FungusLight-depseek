## 补充：项目工作约定

- 接续先读 `README.md`、`game/DEV_STATE.md`、`qa/gates.json` 与当前策划。
- 每轮实际验证，更新接续记录，使用 Conventional Commits 提交并推送。
- 保留历史证据，不伪造人工审核，不提交个人存档、缓存或调试日志。
- G2 后人工审核动作/特效；G3～G6 未完成时不得宣称整款游戏完成。
- 功能或阶段变化时同步 README 与策划文首交接快照。
- 对外发布前确认原始素材、生成图和音乐许可。

## 当前确定的要求

- **游戏方向：** Godot 4.3，单角色俯视角动作 RPG，近战＋法术，无伙伴支援。
- **内容：** 五章、37 节点、P01～P09、M1～M4、6 装备、两结局、Boss/精英。
- **表现：** 像素风、分层技能特效、传送门暖色椭圆内部微光、Boss BGM、低特效/减少动态/降低闪光。
- **质量：** 固定步战斗、真实输入回放、存档/坏档恢复、PCK/布局/干净目录启动检查。
- **验收：** G2 后 H2 人工审核；G6-012 由用户签署通过。
- **边界：** 自动路线 707.7 秒不是 20 分钟真人时长；8/8 矩阵是 G6-003 历史基线；素材/生成图/Boss BGM 再分发许可仍需确认。
