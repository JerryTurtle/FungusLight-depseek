# 《菌灯之下》G6-003 操作与运行说明

## 启动

1. 解压发布包到任意可写目录；`Game/` 内的 `FungusLight.exe` 与 `FungusLight.pck` 必须保持同目录。
2. 双击 `开始游戏.cmd`，或直接双击 `FungusLight.exe`。
3. 发布版默认进入标题画面，不再进入 G2 审核台；不需要 Godot 编辑器、Python 或本机开发路径。
4. 第一次运行会在用户目录创建 `FungusLight` 配置与存档目录。若系统禁止写入，程序会尝试 `LOCALAPPDATA`、文档目录或 exe 旁的 `用户数据/`。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 灯击（近战） | 鼠标左键 |
| 净光（直线） | 鼠标右键 |
| 护灯 | 1 |
| 灯雨 | 2 |
| 闪避 | 空格 |
| 交互 / 对话推进 | E、回车或空格 |
| 观察 | Q |
| 治疗 | R（消耗药剂） |
| 暂停 / 返回 | Esc |
| 设置 | F1，或标题/暂停菜单的“设置” |

设置包含全屏、低特效、减少动态、降低闪光和音效音量；设置写入用户目录的 `presentation.cfg`，与存档分离。当前版本不提供按键重设。

## 存档

- 自动存档：新游戏、安全检查点、休息、成长选择、章节推进和结局选择时写入。
- 手动存档：暂停菜单可保存到 3 个手动槽；覆盖已有槽需要确认。
- 读取：标题或暂停菜单的“读取存档”，显示槽位、区域和有效时长；空槽与损坏槽会禁用/给出恢复提示。
- 损坏主档会保留有效 `.bak`；读取失败时可选择恢复上一次有效备份。
- 存档位于 `%APPDATA%\FungusLight\saves\`（或程序选择的后备用户目录）。

## 结局与统计

- 最终核心室压制母体后，在灯根核心选择“恢复共生循环”或“封存并撤离”。
- 尾声显示本次用时与章节记录，可返回标题或读取结局前的自动备份。
- 运行报告写入用户目录的 `run_report.json`，包含构建号、有效时长、结局、章节与通关配置；不写入安装目录。

## 故障排查

- 窗口打不开：确认直接运行的是 `Game/FungusLight.exe`，`.pck` 未被杀软隔离；Windows SmartScreen 可能要求“更多信息 → 仍要运行”。
- 没有声音：检查设置中的音效音量；本版本只有程序音效，没有地区音乐。
- 存档不可写：把游戏放到用户可写目录，或用标题/暂停菜单确认存档提示；发布包本身不含个人存档。
- 字体显示异常：确认使用发布包内字体，不要只复制 exe 而漏掉 pck。
- 许可证/分发：原始 Fungus Cave 素材的再分发许可尚未确认，详见 `Licenses/ASSET-RIGHTS.md`；在确认前请仅用于本项目验收，不要公开商业分发。
