# 《菌灯之下》G6-011 操作与运行说明

## 启动

1. 解压发布包到任意可写目录；`Game/` 内的 `FungusLight.exe` 与 `FungusLight.pck` 必须保持同目录。
2. 双击 `开始游戏.cmd`，或直接双击 `FungusLight.exe`。
3. 发布版默认进入标题画面，不进入 G2 审核台；不需要 Godot 编辑器、Python 或本机开发路径。
4. 标题使用菌洞/灯根/守灯人背景图，标题和菜单居中、无黑框；不再显示剧情介绍或“重看开场故事”。新游戏会先播放五幕开场，回车/空格/左键推进，Esc 跳过。
5. 第一次运行会在用户目录创建 `FungusLight` 配置与存档目录。若系统禁止写入，程序会尝试 `LOCALAPPDATA`、文档目录或 exe 旁的 `用户数据/`。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD（本版本不支持方向键移动） |
| 灯击（近战） | 鼠标左键 |
| 净光（直线） | 鼠标右键 |
| 护灯 | 1 |
| 灯雨 | 2 |
| 闪避 | 空格 |
| 交互 / 对话推进 | E、回车、空格或鼠标左键 |
| 对话中跳过本段 | Tab（选项页不能跳过代选） |
| 观察 / 回声 | Q |
| 饮用药剂 | R（消耗 1 瓶，移动、闪避或受击会取消） |
| 暂停 / 返回 | Esc |
| 设置 | F1，或标题/暂停菜单的“设置” |

## HUD 与技能栏

- 左上：透明无面板的紧凑信息层——小头像、生命、精力、护灯（当前/上限）、三瓶药剂和用时。满瓶为亮色，空瓶为灰色；按 R 后显示药剂饮用进度，完成时出现绿色 `+生命` 数字。
- 净光会沿光路同时命中多个敌人，遇到墙体则截断。
- 右下：灯击、净光、护灯、灯雨、闪避五个 32px 图标；无面板、无格子边框，标注鼠标/数字键/空格。图标变暗并有锁标表示未解锁；竖向遮罩与秒数表示冷却；左上角“耗 N”表示精力消耗，精力不足时变红。
- 顶部章节目标与底部操作提示使用与对话一致的像素字体；顶部指引用“.”分隔章节与房间。
- 灯击、净光、灯雨均有分层像素特效；灯击近战范围 26、角度 130°，面向上/下时内侧贴身目标也会被扫中。
- 其他状态：护灯生效时技能框变为青色；低生命时生命条闪烁；孢毒剩余时间显示在药剂行。
- 暂停与装备面板已加高，底部“返回标题”和装备列表不会再被屏幕裁切。
- 设置面板缩为 420×540、18px 主字号；打开时隐藏 HUD/小地图。
- 32 个休息灯座位于房间安全角，与出口/阀门/箱子的交互提示分开；站在灯座旁按 E 休息，走到出口按 E 进入下一图。

设置只保留全屏、低特效、减少动态、降低闪光、屏幕震动和“音效 / 音乐”；标题页“设置”正常打开，写入用户目录的 `presentation.cfg`。当前版本不提供按键重设。

## 存档

- 自动存档：新游戏、安全检查点、休息、成长选择、章节推进和结局选择时写入。
- 手动存档：暂停菜单可保存到 3 个手动槽；覆盖已有槽需要确认，提示会写明槽位名称。
- 读取：标题或暂停菜单的“读取存档”，显示槽位、区域和有效时长；空槽、损坏槽、仅剩备份分别标注。
- 损坏主档会保留有效 `.bak`；读取失败时可选择恢复上一次备份。
- 存档位于 `%APPDATA%\FungusLight\saves\`（或程序选择的后备用户目录）。

## 结局与统计

- 最终核心室压制母体后，先播放“母体最后的话”，再在灯根核心选择“恢复共生循环”或“封存并撤离”。
- 尾声用 9 句收束岚、禾、绒、砾与避难所的后续，显示结局、本次游玩用时和章节记录；可返回标题或读取结局前的独立备份。
- 运行报告写入用户目录的 `run_report.json`，包含构建号、有效时长、结局、章节与通关配置；不写入安装目录，也不在玩家界面显示绝对路径。

## 故障排查

- 窗口打不开：确认直接运行的是 `Game/FungusLight.exe`，`.pck` 未被杀软隔离；Windows SmartScreen 可能要求“更多信息 → 仍要运行”。
- 没有声音：检查设置中的音效音量；本版本只有程序音效，没有地区音乐。
- 存档不可写：把游戏放到用户可写目录，或用标题/暂停菜单确认存档提示；发布包本身不含个人存档。
- 字体显示异常：确认使用发布包内字体，不要只复制 exe 而漏掉 pck。
- 许可证/分发：原始 Fungus Cave 素材的再分发许可尚未确认，详见 `Licenses/ASSET-RIGHTS.md`；在确认前请仅用于本项目验收，不要公开商业分发。
