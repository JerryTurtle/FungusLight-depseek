# G6-013 兼容性修复说明

## 1. 问题

G6-012 发布包在部分低配/老电脑上无法启动。发布机制、引擎版本和游戏逻辑本身没有故意设置门槛，问题出在**构建架构、图形驱动回退和启动诊断**三个环节：

| 现象 | 根因 | 证据 | G6-013 处理 |
| --- | --- | --- | --- |
| 双击后 Windows 直接报“不是有效的 Win32 应用程序”/毫无反应 | G6-012 只有 `x86_64` 构建；32 位 Windows 无法加载 64 位 PE | 发布 exe 的 PE Machine 为 `0x8664`；32 位系统只能运行 `0x014C` | 同时发布 x86_64 + x86_32 两个官方模板构建；`Game/FungusLight.exe` 默认为 32 位，32/64 位 Windows 双击都能运行；启动器在 64 位系统优先选 `64/FungusLight.exe` |
| 有窗口但黑屏、闪退，或提示显卡驱动不支持 | Compatibility 渲染器要求 OpenGL 3.3；老 Intel/AMD 驱动可能只报告更低版本，或原生 GL 上下文创建失败 | 引擎在 `gl_info.version < 30003` 时才自动切换 ANGLE；驱动在创建上下文阶段崩溃时没有机会回退 | 主启动器首次失败会自动再试 `--rendering-driver opengl3_angle`；另提供 `兼容模式启动.cmd` 直接强制 ANGLE/D3D11 |
| 老电脑上启动后没有任何提示 | 发布构建关闭了引擎日志；原 `开始游戏.cmd` 用 `start` 启动且不写日志 | G6-012 `project.godot` 中 `file_logging` 为 false；旧 cmd 只有一行 `start` | 启动器统一传 `--log-file`；游戏启动时写 `startup-info.txt`/`compat_report.json`；`系统检查.cmd` 汇总系统、显卡、文件与日志 |
| 小屏笔记本上标题/菜单跑到屏幕外 | 固定 1280×720 窗口，1024×768 等屏幕放不下 | 窗口尺寸写死 1280×720 | 按屏幕可用区等比缩小并居中；大屏仍保持 1280×720 |
| 低配机器帧率低、粒子多 | 特效默认全开 | 旧设置只有手动“低特效”开关 | 首次运行检测 ≤2 线程或老 iGPU 时自动开启低特效/减少动态，设置面板仍可改回并持久化 |

## 2. 不会改变 H2 已审内容

本次只改**启动、构建、诊断和窗口适配**；战斗时序、握持/动作、命中范围、Boss 判定、相机、特效构图、剧情与时序全部沿用 G6-012。ANGLE 兼容模式在同一台机器上截图的像素与原生 OpenGL 完全一致（1280×720，差异像素 0）。

## 3. 验证

- 64 位发布构建：干净目录 headless 启动 `exit 0`，输出 `COMPAT_ARCH x86_64`、`RELEASE_BOOT campaign`。
- 32 位发布构建：同一套流程 `exit 0`，输出 `COMPAT_ARCH x86_32`、`RELEASE_BOOT campaign`；在 64 位 Windows 的 WOW64 下实机窗口启动正常。
- 32 位 QA 构建：`test_g6_compat` 34/34、`test_g6_release` 39/39 通过。
- ANGLE 兼容模式：`OpenGL ES 3.0.0 (ANGLE 2.1.1 ...)`，Radeon 780M / D3D11，标题截图与原生 GL 逐像素一致。
- 启动器选择：64 位系统选中 `64\FungusLight.exe`；模拟 32 位（`PROCESSOR_ARCHITECTURE=x86`）选中 `FungusLight.exe`；失败重试路径已用返回码 1 的替身程序验证。
- 现有回归：`test_g6_release` 39/0、`test_g4_campaign` 95/0、`test_g4` 48/0、`test_g4_boss` 71/0、`test_g4_death` 5/0、`test_g4_visual` 15/0、`test_g4_presentation` 48/0、`test_save` 65/0、`test_enemies` 73/0、`test_dialogue` 175/0、`test_props` 2464/0、`test_pressure` 5/0、`test_combat` 550/0。路线/跳过路线本轮未重跑（本轮未改战斗、移动、房间或遭遇，沿用 G6-012 基线）。

## 4. 玩家/测试者怎么用

1. 解压后优先双击 **`开始游戏.cmd`**。它会自动选 32/64 位，并在首次失败时自动尝试 ANGLE。
2. 黑屏、闪退、提示显卡驱动问题：双击 **`兼容模式启动.cmd`**。
3. 仍然无法启动：双击 **`系统检查.cmd`**，生成 `diagnostic.txt`；把 `diagnostic.txt`、同目录的 `startup-log.txt` 或 `compat-log.txt`、用户目录里的 `startup-info.txt` 一起反馈。
4. 32 位 Windows 也可以直接双击 `FungusLight.exe`（默认就是 32 位构建）。

## 5. 仍然存在的边界

- Windows XP 不受 Godot 4.3 支持；Windows 7/8/8.1 为 best-effort（引擎官方说明）。
- 32 位进程受 2 GB 地址空间限制；本游戏资源量远低于该限制，但极低内存机器仍可能不足。
- 只有 D3D9、连 D3D11 都不支持的显卡无法通过 ANGLE 启动；本包不附带软件渲染器。
- 没有代码签名/安装器，SmartScreen 可能提示“未知发布者”。
- 原始 Fungus Cave 素材、标题/开场生成图、Boss BGM 的再分发许可仍需权利人确认。
