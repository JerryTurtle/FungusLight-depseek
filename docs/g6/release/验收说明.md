2. **开始界面**：标题与菜单居中、无黑框、像素字体；没有剧情介绍和“重看开场故事”按钮；背景图清晰，文字可读。
3. **开场动画**：标题 → 新游戏 → 五幕开场；确认世界/旧约/禾抬压/砍根/菌群反击/三证据/两种选择能一眼读懂，字幕不挤压，回车/空格/左键推进，Esc 可跳过；标题不再提供开场回看，最后一页提示“进入营地”。
4. **HUD 与技能栏**：营地苏醒后确认左上为透明紧凑信息层；右下五个技能图标、冷却/锁标/“耗 N”；灯击弧光/内圈符文、净光光丝/端部符文、灯雨法阵/光柱/冲击环是否清楚；净光光路多目标与墙截断。
