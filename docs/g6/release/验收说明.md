1. **干净目录首次启动**：把 `Release/Game/` 复制到不含仓库、Godot、Python 的空目录（路径可含空格），双击启动；应直接出现标题，不出现 G2 审核台、调试控制台或开发路径。
2. **新游戏**：标题 → 新游戏 → 营地苏醒 → 可移动、交互、战斗；自动存档出现。
3. **设置**：标题/暂停 → 设置；切换全屏、低特效、减少动态、降低闪光、音效音量；退出重开确认全屏/音量保持。

5. **坏档恢复**：在用户目录把某个手动槽主档改为无效 JSON，保留 `.bak`；读取时应提示并允许恢复备份，不得静默清档。
6. **暂停/死亡**：暂停可继续、保存、读取、设置、返回标题；死亡界面应提供当前区域重试、读取存档、返回标题。

9. **表现复核**：初燃粒子停留与轻震、灯头火焰、导光光束、向右/上下移动手感；确认没有新的遮挡或卡顿。
