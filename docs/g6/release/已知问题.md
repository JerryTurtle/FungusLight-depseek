- 自动验证使用 Godot headless/导出二进制，不替代真实键鼠、显示器刷新率、音频设备和 Alt+Tab 焦点体验。

- 不提供断电级事务保证；写入采用临时文件+回读，损坏主档保留 `.bak` 供显式恢复。
