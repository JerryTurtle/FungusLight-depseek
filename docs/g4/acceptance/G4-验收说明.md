# 《菌灯之下》G4-001 阶段验收包

> **状态：G4 未通过。** 这是“五章结构 + 路线矩阵 + 时长/Boss 复核”的验收包，不是 G4 完成包。
> 当前包用于让你检查内容规模、双支路、双结局、Boss 与操作体验；G4 仍为 `in_progress`。

## 1. 运行

双击本目录的 **`G4-Acceptance.cmd`** 进入 G4 五章主线（营地→菌洞→根桥→分流室→排水/被困门外→合流→泵站→控制室→王庭→调压→核心室→尾声）。

其他入口：

- `G2-Review.cmd`：原有 G2 动作审核台（H01～H06）
- `Enemy-Arena.cmd`：敌人专项练习场

需要保留同目录的 `FungusLight.exe` 与 `FungusLight.pck`；无需安装 Godot。

## 3. 建议验收顺序

1. **新游戏**：从营地床铺苏醒，确认床铺/角色/火把/门碰撞与石拱出口。
2. **序章—第一章**：S01、P01、M1、P02、N1-03 前厅、N1-04 裂口、N1-05 灯根祭坛、N1-06 根桥。
3. **第二章**：先走 A 支路（N2-02→N2-03），返回分流室；再走 B 支路（N2-04→N2-05），返回后进合流门 N2-06。
4. **第三章**：N3-01→N3-06，完成 P07/P08、M4。
5. **终章**：N4-01→N4-06，完成 P09，进入核心室击败 Boss，选择恢复或封存，查看 N4-07 尾声。
6. 记录：章节分项耗时、所选支路顺序、结局、Boss 阶段、卡死/卡墙/数值问题。

请把 `G4-验收记录.md` 填好，重点给出：

1. 从营地到尾声的实际总时长；
2. 第二章先走 A 还是 B、两条支路是否都独立可达；

5. 任何卡墙、卡门、无法交互、数值异常与卡顿。

在这些数据回来前，G4 不能标 `passed`。
