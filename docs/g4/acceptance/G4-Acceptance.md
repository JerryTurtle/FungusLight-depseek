## 1. 运行

双击 **`G4-Acceptance.cmd`** 进入 G4 主线。其他入口：

- `G2-Review.cmd`：G2 动作审核台（H01～H06）
- `Enemy-Arena.cmd`：敌人专项练习场

保留同目录 `FungusLight.exe` 与 `FungusLight.pck`，无需安装 Godot。

## 3. 建议验收顺序

1. 营地苏醒 → 储藏间（P01/M1）→ 隔间 → 旧通道 → 菌洞入口。
2. 导光间（P02）→ 前厅（T3/EL1）→ 裂口 → **菌灯井（新）** → 灯根祭坛（M2）→ 根桥 → **根桥下层（新）**。
3. 分流室：先走 A（排水入口→排水出口），返回；再走 B（被困门外→安全旁室），返回；进合流通道。
4. 泵站守卫（EL2）→ **泵站回廊（新）** → 控制室（M3）→ **试验段外廊（新）** → 王庭外环。
5. 王庭外环 → 供给回廊 → 旧约墙 → **王庭侧廊（新）** → 王庭前厅 → 王庭安全区（M4）→ 回流桥。
6. 调压入口/中段/稳压台（P09）→ 核心外廊 → 最后灯座 → 核心室 Boss → 恢复/封存 → 尾声。
